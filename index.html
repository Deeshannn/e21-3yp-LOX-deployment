01 — The Problem

Why Secure Storage
Matters in Sri Lanka

From multimodal transport hubs to university campuses, people lack safe, smart places to store their belongings temporarily — resulting in theft, inconvenience, and insecurity.

🚌
No Temporary Storage at Hubs

With growing multimodal transport centers like Kadawatha and Makumbura, commuters need a safe, temporary place to store bags without carrying them everywhere.

→ Need smart, accessible storage
🧳
Tourism Luggage Challenges

Sri Lanka sees 1.6M+ tourist arrivals annually. Visitors struggle with luggage at bus stands, railways, temples, and beaches — often paying extra for hotel or driver storage.

→ Need traveler-friendly lockers
🏫
Insecure Campus Storage

Universities and workplaces have open bag storage with no security. Backpacks, earbuds, chargers and laptops are regularly stolen from faculty canteens and libraries.

→ Need accountable, locked storage
🏷️
Weak Token Security

Supermarkets and textile shops use paper/plastic tokens that can be copied or lost. Staff make errors. No digital record exists when a bag goes missing.

→ Need tamper-proof authentication
💸
High Manual Security Cost

Hiring staff solely to watch bags is expensive and inefficient. There is no centralized management, real-time status, or automated accountability.

→ Need automated IoT-based system
⚠️
No Accountability on Loss

When items are lost, no one takes responsibility. Shops explicitly disclaim liability. There is no digital log, no timestamp, and no evidence trail for disputes.

→ Need digital records & traceability
02 — Our Solution

Introducing LoX — Two Systems,
One Smart Platform

LoX offers two complementary locker systems tailored to different use cases — a mobile app-controlled system for identified users, and a smart token-based system for anonymous, short-term access.

Mobile App Based Locker System

  • ✓User registration & secure login — identified users can reserve and manage their locker remotely
  • ✓Real-time locker availability — check and reserve lockers before arriving at the location
  • ✓Remote lock & unlock control — control access from your smartphone via low-latency MQTT
  • ✓Live door status monitoring — get real-time alerts on door state and tamper attempts
  • ✓Time-based usage & payment — automatic billing by duration with digital payment integration
  • ✓Smart Queue system — analytics-driven queue management for peak usage periods
  • ✓Offline fallback — locker logs data locally when internet is unavailable
  • ✓Separate battery backup per locker unit for uninterrupted operation

📍 Target: Bus stands, railway stations, universities, gyms, workplaces, Urban Development Authority

📱
App-Controlled Smart Locker
ESP32 · Flutter · Node.js · MQTT · AWS
Identified Users Locker Network Access Request Long-term Use

Token Based Locker System

  • ✓Smart Power Token — a unique, unforgeable physical token permanently paired to each locker unit
  • ✓Toaster-style token pop-up — token automatically ejects when locker is rented; returned to charge on lock
  • ✓Alert system through token — vibration, LED indication, and buzzer for real-time tamper alerts
  • ✓Crash detection sensor — identifies physical attacks or harmful events on the locker
  • ✓Autonomous Locker Station — local Node.js + PostgreSQL controller manages all lockers independently
  • ✓No mobile app needed — admin dashboard only; zero friction for anonymous short-term users
  • ✓Dual lock mechanism — solenoid primary lock + software-based secondary lock
  • ✓Separate battery backup for both token and locker unit ensures continuity

📍 Target: Supermarkets, textile shops, shopping malls (Keells, SPAR, textile counters)

03 — What Makes Us Unique

Features No Traditional
Locker Offers

Unlike conventional key-based or passcode lockers, LoX brings real-time intelligence, remote control, and physical security alerts together in one cohesive system.

⚡
Smart Power Token

A physical ESP32-powered token that charges inside the locker and communicates via Wi-Fi — alerting owners through vibration, LED, and buzzer when tampered.

📈
Analytics & Smart Queue

Locker usage data is aggregated for administrators to analyze peak times, optimize locker count, and manage queues intelligently.

🛡️
Multi-Layer Breach Detection

Tamper detection sensors, vibration sensors, collision detection, and door state monitoring combine to provide comprehensive security coverage.

🔌
Plug & Play Scalability

Add new lockers to the network without complex setup. Each unit connects autonomously to the locker station via MQTT/Wi-Fi.

🏪
Locker Marketplace

Organizations can purchase LoX locker units directly through an integrated marketplace. One platform for hardware, software, and management.

🔋
Per-Unit Battery Backup

Each locker unit and power token has its own lithium-ion battery backup ensuring uninterrupted operation during power failures.

06 — Hardware Components

Carefully Selected
Hardware for Reliability

Each hardware component was chosen for its specific role in delivering a secure, responsive, and energy-efficient locker system.

🧠
ESP32 Microcontroller

Central controller with built-in Wi-Fi for real-time communication between the locker, cloud, and mobile app.

🔒
Solenoid Door Lock

Enables secure, fast, electronically controlled locking and unlocking triggered remotely or by token.

📏
Ultrasonic Sensor

Detects whether goods are stored inside the locker to prevent unauthorized access or abandoned items.

💡
IR Sensor

Detects door open/close status and object presence to ensure correct locker usage and prevent misuse.

🖥️
LCD Display

Provides clear, real-time instructions and status messages to users at the physical locker station.

🔔
Buzzer / Alarm

Immediately alerts users and nearby staff during unauthorized access or security breaches.

📳
Vibration Sensor

Provides haptic feedback and security signaling on the Power Token when the locker is tampered.

💥
Collision Sensor

Identifies harmful physical events or attacks on the locker structure and triggers immediate alerts.

🔋
Lithium-Ion Battery

Ensures uninterrupted locker operation during power failures. Separate backup per unit and token.

💚
LED Indicators

Visually show locker status — available, in-use, or error — for quick and easy user guidance.
